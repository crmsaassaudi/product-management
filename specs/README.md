# specs/

Spec/PRD nháp trước khi lên issue GitHub - tùy chọn, không bắt buộc cho mọi feature. Dùng khi feature đủ lớn/phức tạp để cần bàn bạc trước (vấn đề, mục tiêu, phạm vi, repo bị ảnh hưởng, tiêu chí hoàn thành) trước khi chốt thành issue.

Quy ước đặt tên file: `<slug-ngắn>.md`. Sau khi issue được tạo, thêm link issue vào đầu file spec tương ứng.
